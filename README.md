# Insighta

Web & App Usage Analytics Dashboard

## About

Insighta is an analytics dashboard built to visualize web and app usage data — helping track user activity, engagement patterns, and key usage metrics through a clean, interactive interface.

## Features

- 📊 Interactive charts and visualizations for usage metrics
- 📈 Track user engagement and activity trends over time
- 🎨 Clean, responsive UI built with reusable components
- ⚡ Fast development and build experience

## Tech Stack

- **Language: TypeScript
- **Build Tool: Vite
- **Package Manager: [Bun](https://bun.sh)
- **UI Components: shadcn/ui
- **Styling:** CSS
- **Linting/Formatting:** ESLint, Prettier

## Getting Started

### Prerequisites

- [Bun](https://bun.sh) installed on your machine

### Installation

```bash
# Clone the repository
git clone https://github.com/khanrafiya/Insights-intern.git
cd Insights-intern

# Install dependencies
bun install
```

### Running Locally

```bash
bun run dev
```

The app will be available at `http://localhost:5173` (default Vite port).

### Build

```bash
bun run build
```
